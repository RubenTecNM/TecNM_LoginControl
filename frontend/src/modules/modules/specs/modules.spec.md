# Acceso a módulos

La bienvenida muestra los módulos activos asignados y permite abrirlos mediante la URL emitida por el servidor. Superadmin administra catálogo, claves y asignaciones por usuario o módulo. Las claves se muestran únicamente al crearlas o reemplazarlas. Las operaciones masivas distinguen seleccionados de todos los usuarios existentes y requieren confirmación para todos. La interfaz informa errores y evita envíos simultáneos; el backend verifica sesión y autorización.
